# Attribution

This repository documents **OntoDL+**, an ontology description language created at the University of Minho.

## OntoDL+

OntoDL+ was created by **Alexandre Costa Dias** (full name in the dissertation: Alexandre Miguel da Costa Dias) as a Master dissertation in Informatics Engineering, University of Minho, October 2021.

The work was supervised by:

- **Pedro Rangel Henriques** (Ph.D.)
- **Cristiana Esteves Araújo** (M.Sc.)

OntoDL+ extends **OntoDL**, an earlier domain-specific language for specifying ontologies.

**Thesis:** Dias, Alexandre Costa. *ONTODL+: an ontology description language and its compiler.* Master's thesis, University of Minho, Braga, Portugal, 2021. <https://hdl.handle.net/1822/81340>

**Official project site:** <https://epl.di.uminho.pt/~gepl/GEPL_DS/OntoDL/>

The dissertation is published open access under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). The grammar in this repository is an adaptation of the ANTLR listings and examples printed in that dissertation (chapters 3 and 5, with supporting examples in chapters 4 and 7). Changes are described in [grammar/NOTES.md](grammar/NOTES.md).

José Carlos Ramalho and Salete Teixeira provided ontologies used to test and demonstrate the language. Those example files are **not** copied here. They remain on the official download page.

## Compiler

The OntoDL+ compiler (Java sources and the published `OntoDL.jar`) is **not** part of this repository. The download page publishes a JAR and does not state a software license. Republishing the compiler would need permission from the authors.
